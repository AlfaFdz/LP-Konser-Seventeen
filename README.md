# SEVENTEEN RIGHT HERE — Concert Landing Page

Landing page bertema konser SEVENTEEN yang dibuat sebagai project pemrograman web.

## Tentang Project

Project ini merupakan landing page yang dirancang untuk menyajikan informasi konser SEVENTEEN dalam tampilan yang menarik dan interaktif. Website berisi informasi acara, jadwal dan venue, pilihan tiket, simulasi pembelian tiket, serta informasi mengenai member dan unit SEVENTEEN.

## Fitur

- Landing page bertema konser
- Informasi acara
- Informasi jadwal dan venue
- Pilihan kategori tiket
- Simulasi pembelian tiket
- Informasi member dan unit
- Navigasi halaman
- Tampilan responsif
- Interaksi menggunakan JavaScript

## Teknologi

- HTML
- CSS
- JavaScript
